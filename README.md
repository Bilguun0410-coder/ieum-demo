# 이음 (IEUM) — AI가 돕는 시니어 자산승계 준비

시니어가 **전문가를 만나기 전에** 가족·재산·증여 이력을 정리하는 서비스의 시연용 웹앱입니다. **AI가 서류 사진을 읽어 재산 목록을 채우고, 상담 브리핑과 질문을 써 주며, 용어를 설명합니다.** 규칙 엔진은 준비 상태를 점검하고 AI 답변에서 세액 추정·유불리 판단 문장을 걸러냅니다.

> **시연용입니다.** 서버가 없고 입력값은 그 기기 브라우저에만 저장됩니다. 결제는 **모의 결제**(실제 청구 없음)이고, 관리자 로그인은 그 기기 안에서만 동작합니다. 세액 계산·법률·세무 자문·법적 유언 작성은 하지 않습니다. **실명·계좌번호·실제 서류를 넣지 마세요.**

- 실행 주소: https://bilguun0410-coder.github.io/ieum-demo/

## 발표 전 준비 (5분)

1. [Google AI Studio](https://aistudio.google.com/apikey)에서 본인 계정으로 API 키를 만듭니다. **키를 저장소나 메신저에 올리지 마세요.**
2. 발표할 PC의 브라우저에서 앱을 열고, 오른쪽 위 **관리자** → 비밀번호 만들기(6자 이상)
3. 관리자 화면 **AI 설정**에 키를 붙여 넣고 저장 → **연결 테스트**에서 "연결됨" 확인
4. 연결이 안 되면 모델을 `gemini-3.5-flash-lite` 등으로 바꿔 다시 테스트
5. 발표가 끝나면 **키 삭제**

## 3분 시연 순서

1. 시작 화면 → **가상 샘플로 둘러보기** (③ 준비 점검 77점, 사전증여 합산 검토 분류)
2. ② 재산·증여 → 견본 서류 **예금 잔액 증명서** 선택 → 동의 체크 → **AI로 읽기** → AI가 읽은 금액·기준일·원문 문구 확인(계좌번호 자동 가림) → 저장하면 "AI 추출" 표시
3. ⑥ 상담 리포트 → **AI 브리핑 만들기** → 리포트에 "AI 작성" 표시로 들어감
4. **AI 도우미** → "유류분이 뭐예요?" → 🔊 읽어주기
5. **이용권** → 자산승계 준비 패키지 모의 결제 → ⑥에서 **리포트 발급하기** → 발급번호가 붙고 인쇄/PDF
6. **관리자** → 모의 매출, 월 손익분기(279건) 진행률, 가격 변경·금액권 발급

## 기능

| 화면 | 내용 |
|---|---|
| ① 가족 | 관계·가명 입력, 수정·삭제, 본인 확인 |
| ② 재산·증여 | **AI 서류 읽기**(사진·PDF → 항목 추출 → 원문 대조 후 저장), 직접 입력, 과거 증여 기록 |
| ③ 준비 점검 | 100점 규칙 점수, 확인 필요 사항, 가정 기준일 기준 사전증여 합산 검토 분류(상속인 10년·그 외 5년) |
| ④ 시나리오 비교 | 증여·상속·배분 쟁점 비교 (세액·유불리 없음) |
| ⑤ 유언 의사 | 의사 정리(법적 효력 없음), 방식별 요건 요약 |
| ⑥ 상담 리포트 | 포함 항목 선택, **AI 상담 브리핑**, 발급권으로 발급(발급 전은 "미리보기" 표시), 인쇄/PDF |
| AI 도우미 | 용어·절차 질문, 음성 입력(지원 브라우저), 읽어주기 |
| 이용권 | 상품, **모의 결제**(카드번호 입력 없음), 금액권 선물·등록, 주문 내역·환불 |
| 내 데이터 | JSON 내려받기·불러오기, 전체 삭제, 개인정보 안내 |
| 관리자 | 모의 매출·손익분기, 상품 가격·판매·추가, 금액권 발급, 이용권 지급, AI 설정, 활동 기록 |

접근성: 글자 3단계, 고대비, 44px 이상 버튼, 키보드 조작, 모바일 대응. 글꼴: [Pretendard](https://github.com/orioncactus/pretendard) (SIL OFL).

## 역할 분리

| | 하는 일 | 하지 않는 일 |
|---|---|---|
| AI (Google Gemini) | 서류 읽기, 상담 브리핑 초안, 용어 설명 | 세액 계산, 유불리 판단, 유언 효력 판단 |
| 규칙 엔진 | 준비 점수, 합산 검토 분류, AI 출력 형식 검증·금지 문장 차단 | 개별 사건의 최종 판단 |
| 이용자 | AI 결과를 원문과 대조, 공개 항목 선택 | — |
| 전문가 | 개별 세무·법률 검토 | — |

## 보안·개인정보

- API 키는 저장소에 없습니다. 관리자가 기기에 입력하며, 내려받기 파일에도 들어가지 않습니다. Google은 실제 서비스에서는 서버를 거쳐 호출하라고 안내합니다.
- AI 버튼을 누를 때만 필요한 정보가 Google Gemini로 전송됩니다. 무료 등급 API는 전송 내용이 Google 제품 개선에 쓰일 수 있습니다.
- 서류 원본 이미지는 저장하지 않습니다. 관리자 비밀번호는 원문이 아닌 해시로만 저장합니다(시연용, 실제 보안 아님).

| `commerce.js` | 이용권·모의 결제·금액권·환불·관리자 규칙 |

| `samples.js` | 견본 서류 이미지 3장 (모두 가상) |
