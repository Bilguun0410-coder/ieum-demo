# 이음 (IEUM) — 시니어를 위한 자산승계 준비 도우미

시니어가 **전문가를 만나기 전에** 가족·재산·증여 이력을 직접 정리하고, 상담에 가져갈 리포트를 만드는 서비스의 시연용 프로토타입입니다.

> **2026-11-26 현재: 서버 없는 정적 웹앱(시연용)입니다.** AI를 사용하지 않고 고정된 규칙으로만 동작합니다. 세액 계산, 법률·세무 자문, 법적 유언 작성, 로그인, 서버 저장, 전문가 연결·결제는 없습니다. **실명·계좌번호·실제 자산 정보를 입력하지 마세요.**

## 30초 시연 (평가자용)

1. `index.html`을 브라우저로 열거나 GitHub Pages 주소로 접속
2. 시작 화면의 **가상 샘플로 둘러보기** 클릭
3. ③ 준비 점검 → 점수와 확인 필요 사항, 사전증여 합산 검토 대상 분류 확인
4. ④ 시나리오 비교 → 세액·"최적안" 없이 확인 쟁점만 나열되는지 확인
5. ⑥ 상담 리포트 → 항목 체크를 끄면 리포트(질문 포함)에서도 그 정보가 사라지는지 확인, 인쇄/PDF 저장

## 구현 범위

| 메뉴 | 내용 |
|---|---|
| 시작 | 서비스 소개, 준비 현황, 역할 분리(나 / 규칙 기반 앱 / 전문가) |
| ① 가족 | 관계·가명 입력, 수정·삭제, 본인 확인 |
| ② 재산·증여 | 부동산·예금·주식·보험·기타·채무, 금액 기준일·확인 상태, 과거 증여 기록 |
| ③ 준비 점검 | 100점 규칙 점수, 확인 필요 사항, 가정 기준일 기준 사전증여 합산 검토 대상 분류 (상속인 10년 / 그 외 5년) |
| ④ 시나리오 비교 | 지금 일부 증여 / 향후 상속 준비 / 가족별 배분 검토를 나란히 비교 (교육용, 세액 없음) |
| ⑤ 유언 의사 | 남기고 싶은 뜻 정리(법적 효력 없음), 방식별 핵심 요건 요약 |
| ⑥ 상담 리포트 | 포함 항목 선택, 질문 자동 정리, 서류 체크, 기한·제도 안내, 인쇄/PDF |
| 내 데이터 | JSON 내려받기·불러오기, 전체 삭제, 개인정보 안내, 파일럿 가격 의향 조사 |

접근성: 글자 3단계, 고대비, 44px 이상 버튼, 키보드 조작, 모바일 폭 대응.
저장: 이 기기 브라우저(localStorage)에만 저장하며 서버로 전송하지 않습니다.

## 이 앱이 하지 않는 것

- 세액 계산, 절세안·최적 배분 제시
- 합산 여부의 확정 (검토 대상으로 **분류**만 함)
- 유언의 효력 판단·작성 대행
- 신고 대행, 금융상품 추천, 자동 계좌 조회, OCR

## 실행 방법

- **로컬**: 저장소를 내려받아 `index.html`을 Chrome·Edge·Safari로 엽니다. (빌드·설치 없음)
- **GitHub Pages**: 저장소 Settings → Pages → Deploy from a branch → `main` / (root). 배포 후 표시되는 주소로 접속합니다. 배포 여부는 설정에서 확인하세요.

## 검증

```bash
node --test tests/logic.test.js   # 규칙·검증 로직 단위 테스트 (Node 18+)
node tests/smoke.js               # 브라우저 통합 점검 (playwright 필요, 파일 상단 안내 참고)
```

- `logic.js`: 화면과 무관한 규칙(점수, 합산 검토 분류, 입력 검증, 가져오기 검증)
- `app.js`: 화면과 저장
- 경계일(정확히 N년 전 포함), 2월 29일, 잘못된 날짜·금액, 손상된 저장값, 잘못된 가져오기 파일, HTML 삽입 시도를 테스트합니다.
