# 이음 (IEUM) — 가족 자산승계 준비·전문가 협업 MVP

이음은 가족과 세무·법무 전문가가 상속·증여 준비 자료를 체계적으로 정리하고 상담 전에 확인할 항목을 관리하는 플랫폼을 목표로 합니다.

> **2026-11-17 현재: 기능 시연용 정적 웹앱입니다.** 실제 AI 호출, 세액 계산, 법적 유언 작성, 로그인·권한 관리, 서버 데이터 저장, 전문가 연결·결제 기능은 구현되지 않았습니다. 실명·계좌번호·실제 자산정보를 입력하지 마세요.

## 구현된 기능

| 메뉴 | 구현 내용 |
|---|---|
| 서비스 소개 | 서비스 목적, 데모 범위 안내 |
| 가족 등록 | 가족 구성원의 관계·가명 입력, 목록 조회·삭제 |
| 재산·증여 기록 | 부동산·예금·주식·기타 자산·채무 등록, 단순 총합, 증여일·수증자 기록 |
| 대시보드 | 예시 사건 수, 서류 점검 현황 |
| 사건 관리 | 시연용 사건 등록 및 진행상태 표시 |
| 서류 관리 | 예시 체크리스트 확인·미확인 상태 |
| 일정 관리 | 법적 기한 확정 없이 주요 준비사항 안내 |
| 전문가 검토 | 담당자 업무 보드 예시 |
| 상담 준비 리포트 | 가족·재산·증여 입력정보, 준비도, 상담 질문 정리, 브라우저 인쇄/PDF |

**저장 방식:** 입력 값은 현재 페이지를 닫거나 새로고침하면 사라집니다. 테스트용 가상 정보만 사용하세요.

## 실행 방법

### 방법 1 — 로컬
1. 저장소의 `index.html`을 내려받습니다.
2. 파일을 Chrome, Safari, Edge 등 웹브라우저로 엽니다.
3. 가족 등록 → 재산·증여 기록 → 서류 관리 → 상담 준비 리포트 순으로 사용합니다.
4. 리포트 메뉴에서 **인쇄하거나 PDF로 저장**을 눌러 시연 결과를 보관할 수 있습니다.

### 방법 2 — GitHub Pages
1. 저장소 → **Settings → Pages** 메뉴.
2. **Build and deployment → Deploy from a branch** 선택.
3. **main / (root)** 선택 후 **Save**.
4. GitHub가 표시하는 실제 배포 URL에서 접속합니다. 배포 여부는 저장소 설정에서 별도로 확인해야 합니다.

## 시연용 테스트 시나리오
1. 가족 등록에서 ‘배우자’, ‘첫째 자녀’ 같은 가명을 추가한다.
2. 재산·증여 기록에서 가상의 부동산 500,000,000원, 예금 50,000,000원, 채무 20,000,000원을 추가한다.
3. 자산 합계 550,000,000원, 채무 20,000,000원, 단순 차액 530,000,000원이 표시되는지 확인한다.
4. 가상의 과거 증여를 입력한다.
5. 서류 관리에서 예시 체크리스트를 확인한다.
6. 상담 준비 리포트에서 입력 요약과 누락 항목을 확인하고 인쇄/PDF 기능을 실행한다.
7. 삭제/초기화 기능을 시험하고, 새로고침하면 입력값이 사라지는지 확인한다.

> 위 계산은 단순 산술 합계이며 **상속세 계산이 아닙니다.**
