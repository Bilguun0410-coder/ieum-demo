# 이음 (IEUM)

**AI 가족 자산승계 준비·상속 실행 협업 플랫폼 — 프론트엔드 데모**

가족과 세무·법무 전문가가 상속 사건의 서류, 일정, 업무 상태를 한곳에서 확인할 수 있도록 기획한 서비스입니다.

## 데모 기능
- 서비스 소개와 대시보드
- 상속 사건 추가 및 상태 표시
- 서류 체크리스트 체크 및 진행률 표시
- 상속 관련 일정 확인 항목
- 전문가 검토 업무 보드 (예시)

## 실행 방법
`index.html` 파일을 브라우저로 열면 됩니다. 별도 설치가 필요하지 않습니다.

## GitHub Pages 배포
1. GitHub에서 공개 저장소 `ieum-demo`를 생성합니다.
2. 이 폴더의 `index.html`, `README.md`를 저장소 최상위에 업로드합니다.
3. **Settings → Pages → Build and deployment → Deploy from a branch**를 선택합니다.
4. `main` 브랜치와 `/(root)`를 선택한 뒤 저장합니다.
5. 배포가 완료되면 Pages에 표시되는 URL에서 웹사이트를 확인합니다.

## 향후 개발 계획
- 계정·역할별 접근권한과 감사 로그
- 암호화된 문서 저장 및 전문가 검토
- OCR·AI 추출과 원문 근거 표시
- 업무 기한 알림, 사건 요약 PDF
- 시니어용 접근성 개선

## 주의
이 저장소는 **사업계획 검토를 위한 시연용 프론트엔드**입니다. 실제 AI, 인증, 서버 저장, 문서 업로드, 자동 신고, 법률·세무 판단 기능은 구현되어 있지 않습니다. 입력한 내용은 페이지 새로고침 시 초기화됩니다. 실제 개인정보나 민감한 상속 자료를 입력하지 마세요.
