# 계획서 보완 메모 (2026-11-26, AI·이용권 반영판)

원본 계획서(사업 개발서)는 수정하지 않았습니다. 이 문서는 계획서를 투자자·평가자 관점으로 점검한 뒤 **앱 구현에 반영한 결정**과 **아직 증거가 없는 부분**을 구분해 기록합니다. 숫자는 모두 가설이며, 검증되지 않은 값은 그렇게 표시했습니다.

## 1. 가장 큰 문제였던 것

| 문제 | 조치 |
|---|---|
| 계획서는 시니어 직접 사용(B2C)인데 기존 앱은 "사건 관리·일정 관리·전문가 업무 보드" 같은 전문가 협업 도구였다 | 계획서 P0에 없는 화면을 삭제하고 계획서 P0를 모두 구현 |
| 계획서의 "AI 재산 목록 정리"와 "AI·규칙·전문가 역할 분리"가 화면에 없었다 | 생성형 AI(Google Gemini)로 서류 읽기·상담 브리핑·도우미를 구현하고, 규칙 엔진이 AI 출력을 검사하는 구조로 역할을 화면과 리포트에 표시 |
| 시니어 대상인데 글자 12–14px, 입력 저장 없음, 인쇄 외 확인 수단 없음 | 기본 18px, 3단계 확대, 고대비, 44px 터치 영역, 자동 저장, 내보내기·삭제 |
| 이용자 검증 0건 | `docs/pilot-protocol.md`로 사용성 테스트·가격 의향 조사 절차 준비 (실행 전) |

## 3. 일부러 삭제·축소한 것

- **사건 관리, 일정 관리, 전문가 업무 보드, 대시보드**: 전문가가 쓰는 B2B 업무 도구에 가깝고 계획서 P0 어디에도 없다. 전문가 연결은 변호사법·세무사법 검토와 운영 인력이 필요해 12주 MVP 범위 밖이다. 삭제했다.
- **서류 관리 / 전문가 검토**: 리포트 안의 "상담 때 챙길 서류" 체크리스트와 "전문가에게 물어볼 질문"으로 합쳤다.
- **법적 기한 확정 안내**: 기한은 "일반 정보"로만 표시하고 출처와 "전문가 확인 필요"를 붙였다.

## 4. 규제 경계 (설계 근거)

- **변호사법 제109조**: 변호사가 아닌 사람이 대가를 받고 법률사무(법률상담, 법률관계 문서 작성 등)를 하면 처벌 대상이 될 수 있다. 유료 리포트(가설 89,000원)가 이 경계 위에 있다는 점이 가장 큰 사업 리스크다.
- **참고 판단**: 서울고등법원 2025누6423은 정해진 질문에 따라 입력받아 문서를 만드는 서비스가 변호사법 위반으로 보기 어렵다고 보았고, 이용자의 개별 상황에 법률 판단을 더하는 경우에는 위반 소지가 있다고 언급했다는 보도가 있다. 서울지방변호사회가 상고를 검토 중이라고 보도되어 **확정된 기준이 아니다.** (출처: 법률신문 https://www.lawtimes.co.kr/news/212408, 1심 서울행정법원 2023구합60018 https://www.lawtimes.co.kr/news/207705) 판결문 원문과 상고 결과는 상용화 전에 법무 전문가가 직접 확인해야 한다.
- **설계 대응**: 입력값을 정리·분류만 하고 개별 법률·세무 판단(합산 확정, 절세안, 유언 효력)을 하지 않는다. 시나리오 화면은 "무엇을 확인할지"만 나열한다. 이 대응이 충분한지는 **변호사 검토 전까지 [추측]** 이다.
- **세무사법**: 세액 계산·신고 대행을 하지 않는다. 같은 이유로 세액은 어디에도 표시하지 않는다.
- **개인정보**: 가족관계와 재산 정보는 유출 시 피해가 크다. 데모는 서버가 없고 로컬 저장만 한다. 서버 도입 시 동의·최소 수집·암호화·보관 기간 설계와 법무 검토가 필요하다.

## 5. 경쟁 대안 (직접 확인 전 가설)

계획서의 비교는 일반적인 대안 설명 수준이었다. 평가자는 "이미 있는 것과 뭐가 다른가"를 먼저 묻는다. 아래는 **가설**이며, 각 서비스를 직접 써 보고 비교표로 채워야 한다. (미완료)

| 대안 | 예상되는 강점 | 이음이 주장할 수 있는 차별점 (검증 필요) |
|---|---|---|
| 엔딩노트 계열 앱 (예: 엔딩노트 앱, 브이힐즈) | 인지도, 정서적 정리 중심 | 재산·증여 이력의 구조화, 사전증여 합산 검토 분류, 전문가 상담용 출력 |
| 은행·증권사 상속·유언 서비스 | 신뢰, 자산 연결 | 특정 금융사에 묶이지 않는 중립적 정리, 상품 판매 목적 없음 |
| 로펌·세무법인 직접 상담 | 전문성 | 상담 전 준비로 상담 시간을 줄임 |
| 정부24 안심상속 원스톱서비스 | 무료, 공식 | **사망 후**에만 쓸 수 있고, 조회 항목에 명시되지 않은 재산은 따로 확인이 필요할 수 있음. 이음은 **생전** 정리 |

안심상속 신청은 사망일이 속한 달의 말일부터 1년 이내이며 무료다. (출처: 정부24 https://www.gov.kr/mw/AA020InfoCappView.do?CappBizCD=17400000001)

## 6. 수익성: 계획서 수치의 재계산

계획서 가정: 89,000원(VAT 포함) → 공급가 80,909원, 변동비 15,000원, 고객 확보비(CAC) 30,000원, 고정비 월 1,000만원.

- 건당 공헌이익 = 80,909 − 15,000 − 30,000 = **35,909원**, 손익분기 약 **279건/월**. 산술은 맞다.
- 문제는 CAC다. 30,000원은 근거 없는 가정이다.

| CAC | 건당 공헌이익 | 손익분기 판매량(월) |
|---|---|---|
| 30,000원 | 35,909원 | 279건 |
| 60,000원 | 5,909원 | 1,693건 |
| 100,000원 | −34,091원 | 달성 불가 (건당 적자) |

- 월 279건을 팔려면 유료 전환율이 5%라면 월 활성 이용자 약 5,580명, 2%라면 약 13,950명이 필요하다. 전환율도 근거가 없는 가정이다.
- 계획서 예산 4,600만원은 고정비 월 1,000만원 기준 **4.6개월분**이다. 그 안에 손익분기에 닿으려면 위 깔때기가 성립해야 한다.
- **결론**: 이 모델은 "CAC가 낮게 유지된다"는 한 가지 가정에 거의 전부를 걸고 있다. 파일럿에서 가장 먼저 확인할 것은 가격보다 **고객 확보 경로와 비용**이다. (이 앱에는 결제 기능이 없고, 현재 이용자 수는 0이다.)

## 7. AI 사용 설계 (평가 핵심)

| AI가 하는 일 | 규칙 엔진이 하는 일 | 이용자·전문가가 하는 일 |
|---|---|---|
| 서류 사진에서 재산 항목·금액·기준일·원문 문구 추출 | 추출 결과 형식 검증(분류·금액·날짜), 계좌번호 같은 긴 숫자 가림 | 원문과 대조해 확인 후 저장 |
| 상담 브리핑(요약·더 챙길 것·질문) 초안 | 세액 추정·유불리 권유·효력 단정 문장 자동 차단 후 차단 건수 표시 | 사실 확인, 상담에서 판단 |
| 용어·절차 설명 | 같은 안전장치 적용 | 개별 판단은 전문가 |

- AI 지시문(시스템 규칙)과 출력 후 규칙 검사를 **이중**으로 둔 이유: 지시만으로는 모델이 규칙을 어길 수 있기 때문이다. 차단 기준은 `ai.js`의 `GUARDS`에 있고 테스트로 확인한다.
- AI로 보내는 정보: 이용자가 버튼을 누를 때만, 그 기능에 필요한 것만(서류 이미지 1장, 또는 리포트에 포함하기로 한 가명 정보). 무료 등급 API는 전송 내용이 Google 제품 개선에 쓰일 수 있어 가상 자료만 쓴다.
- API 키: Google은 키를 웹 코드에 넣지 말고 서버에서 호출하라고 안내한다. 시연판은 키를 저장소에 넣지 않고 관리자가 발표 기기에 입력한다. 상용화 시에는 서버 중계가 필수다.
- 모델: 기본값 `gemini-flash-latest`(최신 Flash로 자동 교체되는 별칭). 오류가 나면 관리자 화면에서 다른 모델을 고른다.

## 8. 이번 단계에서 하지 않은 것 (정직한 한계)

- 실제 시니어 이용자 테스트, 세무사·변호사 인터뷰: **0건.** `docs/pilot-protocol.md`는 절차만 준비했다.
- 가격 반응 데이터: 없음. 앱 안의 가격 선택 항목은 파일럿 조사용이며 결제와 무관하다.
- 법령·기한 문구: 공개 자료와 계획서 참고자료 기준 요약이다. 전문가 검토를 받지 않았다.
- 서버·계정·가족 공유·계좌 자동조회: 없음. 자동조회는 계획서의 제외 항목이다.
- 실제 Gemini 호출은 이 환경에서 키 없이 검증할 수 없어, 요청 형식과 응답 처리는 가짜 응답으로 테스트했다. 발표 전에 실제 키로 "연결 테스트"를 반드시 해 본다.
- 관리자 로그인과 결제는 이 기기 안에서만 동작하는 시연용이다. 실제 보안·결제(PG 계약)가 아니다.
